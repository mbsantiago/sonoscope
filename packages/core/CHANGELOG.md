# @sonoscope/core

## 0.2.0

### Minor Changes

- - Introduce 3-tier plugin architecture supporting custom viewers, renderers, and shader programs.
  - Add standalone shader and renderer plugin packages: `@sonoscope/ascii-spectrogram`, `@sonoscope/halftone-spectrogram`, `@sonoscope/terrain-spectrogram`, and `@sonoscope/topographic-spectrogram`.
  - Decouple shader programs, renderer inputs, and performance profiler in core engine.
  - Setup Changesets release infrastructure and Python synchronization.
