Sonoscope features an extensible 3-tier plugin architecture allowing custom viewers, custom canvas renderers, and custom WebGL2 shader programs.

Official plugin packages provide alternative visual representations that integrate directly into the coordinated viewport and navigation engine.

---

## Plugin Showcase

### 1. ASCII Spectrogram (`@sonoscope/ascii-spectrogram`)

Renders the time-frequency spectrum into typography and terminal ASCII characters in real time on an HTML5 canvas.

```bash
npm install @sonoscope/ascii-spectrogram @sonoscope/core
```

```ts
import "@sonoscope/ascii-spectrogram/auto";
import { Sonoscope } from "@sonoscope/core";

const scope = await Sonoscope.fromUrl("/audio/sample.wav");
scope.createSpectrogram(canvas, {
  renderer: "ascii",
  rendererOptions: {
    colorMode: "green", // "colormap" | "monochrome" | "green" | "amber"
    fontSize: 10,
  },
});
```

### 2. Halftone Shader (`@sonoscope/halftone-spectrogram`)

A WebGL2 shader program plugin that transforms the frequency spectrum into a retro halftone dot-matrix print pattern directly on the GPU.

```bash
npm install @sonoscope/halftone-spectrogram @sonoscope/core
```

```ts
import "@sonoscope/halftone-spectrogram/auto";
import { Sonoscope } from "@sonoscope/core";

const scope = await Sonoscope.fromUrl("/audio/sample.wav");
scope.createSpectrogram(canvas, {
  renderer: "halftone",
  minDb: -100,
  maxDb: -30,
});
```

## Plugin Architecture

Sonoscope's plugin system is structured into three extension tiers:

1. **Custom WebGL2 Shader Programs (`registerSpectrogramProgram`)**: Run custom GLSL fragment shaders per tile on the GPU while reusing Sonoscope's tile pipeline, texture management, and coordinate projections.
2. **Custom Spectrogram Renderers (`registerSpectrogramRenderer`)**: Full canvas renderers that receive precomputed STFT power matrices and render on 2D canvas, WebGPU, or custom contexts.
3. **Custom Viewers (`registerViewer`)**: Complete viewer modules that subscribe to Sonoscope's shared viewport controller and audio source lifecycle.
