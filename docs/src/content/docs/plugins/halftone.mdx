## Installation

```bash
npm install @sonoscope/halftone-spectrogram @sonoscope/core
```

---

## Quick start

Importing the `/auto` path automatically registers the `"halftone"` renderer keyword:

```ts
import "@sonoscope/halftone-spectrogram/auto";
import { Sonoscope } from "@sonoscope/core";

const scope = await Sonoscope.fromUrl("/audio/sample.wav");

scope.createSpectrogram(canvas, {
  renderer: "halftone",
  colorMap: "plasma",
  minDb: -100,
  maxDb: -30,
});

scope.attachNavigation(canvas);
```
