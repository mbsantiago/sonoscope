## Installation

```bash
npm install @sonoscope/terrain-spectrogram @sonoscope/core
```

---

## Usage

### Auto-Registration

Importing `@sonoscope/terrain-spectrogram/auto` registers `"terrain"` as a WebGL2 shader program:

```ts
import "@sonoscope/terrain-spectrogram/auto";
import { Sonoscope } from "@sonoscope/core";

const scope = await Sonoscope.fromUrl("/audio/sample.wav");

const spectrogram = scope.createSpectrogram(canvas, {
  renderer: "terrain",
});

scope.attachNavigation(canvas);
```

### Explicit Program Selection

```ts
scope.createSpectrogram(canvas, {
  renderer: {
    type: "webgl",
    program: "terrain",
  },
});
```
