## Ecosystem Architecture

<CardGrid>
	<Card title="@sonoscope/core" icon="puzzle">
		Zero-dependency WebGL2 and WASM rendering engine with decoupled time and frequency navigation, rulers, colormaps, and audio synchronization. See [`@sonoscope/core` Reference](/sonoscope/reference/core/classes/sonoscope/).
	</Card>
	<Card title="@sonoscope/react" icon="seti:react">
		Declarative React components ([`<Spectrogram />`](/sonoscope/reference/react/variables/spectrogram/), [`<Waveform />`](/sonoscope/reference/react/variables/waveform/), [`<TimeRuler />`](/sonoscope/reference/react/variables/timeruler/)) and synchronized audio hooks. See [`@sonoscope/react` Reference](/sonoscope/reference/react/variables/sonoscopeprovider/).
	</Card>
	<Card title="sonoscope (Python / AnyWidget)" icon="seti:python">
		Interactive audio widgets for Jupyter Lab, Jupyter Notebook, VS Code, and Marimo with NumPy array and audio file support. See [AnyWidget Guide](/sonoscope/packages/anywidget/).
	</Card>
	<Card title="WASM & WebGL2 Acceleration" icon="rocket">
		SIMD-optimized STFT analysis in Rust compiled to WebAssembly with high-framerate GPU shader colormap rendering.
	</Card>
</CardGrid>
