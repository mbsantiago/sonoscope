`@sonoscope/react` provides React 18+ and React 19 compatible components and hooks for building custom audio interfaces.

## Components

### [`<SonoscopeProvider />`](/sonoscope/reference/react/variables/sonoscopeprovider/)

Provides the shared Sonoscope instance and coordinated viewport context to child components.

```tsx
import { SonoscopeProvider } from "@sonoscope/react";

<SonoscopeProvider url="/audio/birdsong.wav">
  {/* Nested viewers and rulers */}
</SonoscopeProvider>
```

Full reference: [`SonoscopeProvider`](/sonoscope/reference/react/variables/sonoscopeprovider/), [`SonoscopeProviderProps`](/sonoscope/reference/react/type-aliases/sonoscopeproviderprops/).

### [`<Spectrogram />`](/sonoscope/reference/react/variables/spectrogram/)

Renders an interactive spectrogram canvas synchronized with the provider's scope.

```tsx
import { Spectrogram } from "@sonoscope/react";

<Spectrogram
  height={320}
  colorMap="plasma"
  frequencyScale="mel"
  minValue={-80}
  maxValue={0}
  showAudioControls
/>
```

Full reference: [`Spectrogram`](/sonoscope/reference/react/variables/spectrogram/), [`SpectrogramProps`](/sonoscope/reference/react/type-aliases/spectrogramprops/), [`SpectrogramHandle`](/sonoscope/reference/react/type-aliases/spectrogramhandle/).

### [`<Waveform />`](/sonoscope/reference/react/variables/waveform/)

Renders peak-pyramid accelerated audio waveforms.

```tsx
import { Waveform } from "@sonoscope/react";

<Waveform height={80} colorMap="plasma" />
```

Full reference: [`Waveform`](/sonoscope/reference/react/variables/waveform/), [`WaveformProps`](/sonoscope/reference/react/interfaces/waveformprops/), [`WaveformHandle`](/sonoscope/reference/react/type-aliases/waveformhandle/).

### [`<TimeRuler />`](/sonoscope/reference/react/variables/timeruler/) and [`<FrequencyRuler />`](/sonoscope/reference/react/variables/frequencyruler/)

Renders aligned time and frequency axes with automatic unit scaling.

```tsx
import { TimeRuler, FrequencyRuler } from "@sonoscope/react";

<TimeRuler height={24} tickPosition="top" />
<FrequencyRuler width={56} tickPosition="right" />
```

Full reference: [`TimeRuler`](/sonoscope/reference/react/variables/timeruler/), [`FrequencyRuler`](/sonoscope/reference/react/variables/frequencyruler/), [`TimeRulerProps`](/sonoscope/reference/react/interfaces/timerulerprops/), [`FrequencyRulerProps`](/sonoscope/reference/react/interfaces/frequencyrulerprops/).

## Custom Hooks

- [`useSonoscope(options)`](/sonoscope/reference/react/functions/usesonoscope/): Manage the lifecycle of an independent or shared Sonoscope instance.
- [`useSonoscopeContext()`](/sonoscope/reference/react/functions/usesonoscopecontext/): Access the nearest `Sonoscope` coordinator from context.
- [`useSpectrogram(options)`](/sonoscope/reference/react/functions/usespectrogram/): Direct canvas binding to a `SpectrogramViewer`.
- [`useTimeRuler(options)`](/sonoscope/reference/react/functions/usetimeruler/): Canvas binding for time rulers.
- [`useFrequencyRuler(options)`](/sonoscope/reference/react/functions/usefrequencyruler/): Canvas binding for frequency rulers.
