This live demo runs client-side using `@sonoscope/core` with WebGL2 GPU rendering, dynamic tile caching, and coordinated time/frequency rulers.

### Navigation Controls
- **Scroll / Pinch**: Zoom in and out horizontally (time) and vertically (frequency).
- **Drag**: Pan across time and frequency.
- **Click Rulers / Double Click Canvas**: Seek playback position.

### Implementation Code

<Tabs>
  <TabItem label="TypeScript / Core API">
  ```typescript
  import {
    Sonoscope,
    attachCanvasNavigation,
    attachPlayheadOverlay,
  } from "@sonoscope/core";

  // 1. Initialize Sonoscope from an audio URL or <audio> element
  const audio = document.querySelector<HTMLAudioElement>("audio")!;
  const scope = await Sonoscope.fromUrl("https://.../audio.ogg", {
    audio,
    frequencyScale: "mel",
    followPlayback: "page",
  });

  // 2. Create GPU-accelerated WebGL2 spectrogram
  const specCanvas = document.querySelector<HTMLCanvasElement>("#spec-canvas")!;
  const spec = scope.createSpectrogram(specCanvas, {
    colorMap: "inferno",
    minValue: -80,
    maxValue: 0,
  });
  attachCanvasNavigation(spec, specCanvas);
  attachPlayheadOverlay(specCanvas.parentElement!, scope);

  // 3. Attach synchronized Time and Frequency rulers
  const timeCanvas = document.querySelector<HTMLCanvasElement>("#time-canvas")!;
  const timeRuler = scope.createTimeRuler(timeCanvas, {
    program: "ticks",
    tickPosition: "top",
  });
  attachCanvasNavigation(timeRuler, timeCanvas);

  const freqCanvas = document.querySelector<HTMLCanvasElement>("#freq-canvas")!;
  const freqRuler = scope.createFrequencyRuler(freqCanvas, {
    program: "ticks",
    tickPosition: "right",
  });
  attachCanvasNavigation(freqRuler, freqCanvas);
  ```
  </TabItem>

    );
  }
