Synchronized multi-viewer navigation between a **WebGL2 Spectrogram**, a **Peak-Pyramid Waveform**, and dual **Time & Frequency Rulers**.

- **Scroll / Pinch**: Zoom in/out horizontally (time) and vertically (frequency).
- **Drag**: Pan across time and frequency.
- **Click Rulers / Waveform**: Seek playback position across all synchronized tracks.

<summary><strong>View TypeScript Implementation Code</strong></summary>

```typescript
import {
  Sonoscope,
  attachCanvasNavigation,
  attachPlayheadOverlay,
} from "@sonoscope/core";

// 1. Initialize Sonoscope from an audio URL
const audio = document.querySelector<HTMLAudioElement>("audio")!;
const scope = await Sonoscope.fromUrl(
  "https://upload.wikimedia.org/.../Marico_Sunbird.ogg",
  {
    audio,
    frequencyScale: "mel",
    followPlayback: "page",
  }
);

// 2. Spectrogram Viewer
const specCanvas = document.querySelector<HTMLCanvasElement>("#spec-canvas")!;
const spec = scope.createSpectrogram(specCanvas, { colorMap: "turbo" });
attachCanvasNavigation(spec, specCanvas);
attachPlayheadOverlay(specCanvas.parentElement!, scope);

// 3. Waveform Viewer (Synchronized with scope viewport and playhead)
const waveCanvas = document.querySelector<HTMLCanvasElement>("#wave-canvas")!;
const waveform = scope.createWaveform(waveCanvas, { colorMap: "turbo" });
attachCanvasNavigation(waveform, waveCanvas);
attachPlayheadOverlay(waveCanvas.parentElement!, scope);

// 4. Time and Frequency Rulers
const timeCanvas = document.querySelector<HTMLCanvasElement>("#time-canvas")!;
const timeRuler = scope.createTimeRuler(timeCanvas, { tickPosition: "top" });
attachCanvasNavigation(timeRuler, timeCanvas);
attachPlayheadOverlay(timeCanvas.parentElement!, scope);

const freqCanvas = document.querySelector<HTMLCanvasElement>("#freq-canvas")!;
const freqRuler = scope.createFrequencyRuler(freqCanvas, { tickPosition: "right" });
attachCanvasNavigation(freqRuler, freqCanvas);
```
