This demo illustrates synchronized multi-viewer navigation between a **WebGL2 Spectrogram**, a **Peak-Pyramid Waveform**, and dual **Time & Frequency Rulers**.

### Navigation Controls
- **Scroll / Pinch**: Zoom in and out horizontally (time) and vertically (frequency).
- **Drag**: Pan across time and frequency.
- **Click Rulers / Waveform**: Seek playback position across all synchronized viewers.

### Implementation Code

<Tabs>
  <TabItem label="TypeScript / Core API">
  ```typescript
  import {
    Sonoscope,
    attachCanvasNavigation,
    attachPlayheadOverlay,
  } from "@sonoscope/core";

  const audio = document.querySelector<HTMLAudioElement>("audio")!;
  const scope = await Sonoscope.fromUrl("https://.../audio.ogg", {
    audio,
    frequencyScale: "mel",
    followPlayback: "page",
  });

  // 1. Spectrogram Viewer
  const specCanvas = document.querySelector<HTMLCanvasElement>("#spec-canvas")!;
  const spec = scope.createSpectrogram(specCanvas, { colorMap: "turbo" });
  attachCanvasNavigation(spec, specCanvas);
  attachPlayheadOverlay(specCanvas.parentElement!, scope);

  // 2. Waveform Viewer (Synchronized with scope viewport and playhead)
  const waveCanvas = document.querySelector<HTMLCanvasElement>("#wave-canvas")!;
  const waveform = scope.createWaveform(waveCanvas, { colorMap: "turbo" });
  attachCanvasNavigation(waveform, waveCanvas);
  attachPlayheadOverlay(waveCanvas.parentElement!, scope);

  // 3. Time Ruler
  const timeCanvas = document.querySelector<HTMLCanvasElement>("#time-canvas")!;
  const timeRuler = scope.createTimeRuler(timeCanvas, { tickPosition: "top" });
  attachCanvasNavigation(timeRuler, timeCanvas);
  attachPlayheadOverlay(timeCanvas.parentElement!, scope);
  ```
  </TabItem>
